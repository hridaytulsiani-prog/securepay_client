EscroSafe Label Uploader Privacy Policy

Last updated: 28 October 2026

This policy explains how the EscroSafe Label Uploader Chrome extension processes information when an EscroSafe merchant uses it to upload courier shipment-label PDFs.

Information processed

  • The extension reads the securepay_token cookie only from https://merchant.escrosafe.com to authenticate the signed-in merchant.
  • For completed PDF downloads, it temporarily reads the filename, file type and source URL to identify and retrieve a courier label.
  • It processes shipment-label PDFs selected by the merchant or detected after download and uploads them to EscroSafe.
  • It stores the auto-upload preference and up to 50 recent upload-status records locally in Chrome.

How information is used

Information is used only to authenticate the merchant, upload courier shipment labels, show upload results and provide retry or manual-upload controls.

Data transmission and sharing

The session token and shipment-label PDFs are transmitted over HTTPS only to https://api.escrosafe.com. EscroSafe does not sell extension data or use it for advertising, creditworthiness or lending.

Local storage and control

Recent status records contain a download ID, filename, timestamps, status and message. They do not contain PDF contents, local filesystem paths, source URLs, authentication tokens or API responses. Merchants can clear these records from the popup, turn off automatic upload, or remove the extension.

Limited use

Information obtained through Chrome APIs is used and transferred only as necessary to provide and improve the extension's disclosed label-upload functionality, consistent with the Chrome Web Store User Data Policy.

Contact

For privacy questions or support, use the EscroSafe enquiry page.
